# koishi-plugin-bxg

[![npm](https://img.shields.io/npm/v/koishi-plugin-bxg?style=flat-square)](https://www.npmjs.com/package/koishi-plugin-bxg)

爆小鬼 检测敏感言论并撤回

Notice
1、使用时请务必先确定json路径！
该插件以读取本地json文件方式实现(敏感词里请不要加*?^%等特殊字符)：
格式：{"words": ["敏感词1","敏感词2"]} 

路径尽量不要放到C盘，若遇到json文件读取失败有可能是权限原因</br>
p.s:相关敏感词库json请自行下载或整理...

2、关于命令:bxg.t
提供txt格式转换为本插件可读取的json文件小工具，支持自动识别：
垂直型txt格式:
词1
词2
...
逗号型txt格式:
词1,词2...
转换完毕之后打开json文件再手动添加也是可以的，记得重载插件
注意：输出文件将存放在原txt文件所在的文件夹

Update
v1.0.5更新：
1.禁言功能：开启后可将发送敏感词的用户禁言（由于无法获取禁言状态，所以因权限原因禁言失败不会返回提示）
2.替代功能：开启后可将原话中的屏蔽词变为*重新发送,可以防止刷屏
3.白名单功能：添加到白名单的词将不会被检测
4.日志调试功能：开启后可在日志返回相关信息，详情请在该选项描述中阅读
4.txt格式转换：更新了自动判断txt文件两种格式，无需分别将txt文件放在两个路径下
此版本经测试无问题后，将降低更新速度，感谢下载！
